# Adobe Commerce Developer Agent blueprint and develop stages

The blueprint and develop stages are where a plain-English rule becomes functional, validated code. Using a cart quantity limit as the example, the Adobe Commerce Developer Agent turns the described rule into a formal plan you can review, then writes and self-validates the webhook code in a live workspace.

## Who is this video for?

* Commerce developers
* Solutions architects
* Backend engineers

## Video content

* Describing a business rule (a cart quantity limit) in plain language and generating a blueprint in App Builder mode
* Reviewing the blueprint and plan panel — runtime selection, an enterprise-readiness checklist, and a confidence estimate
* The plan broken into concrete tasks, plus a logic diagram of how the webhook evaluates and blocks the cart add
* The develop stage writes code in a project workspace, with files and code streaming into a Project Explorer
* Automatic build, test, and self-correction, and the agent pausing to ask when it needs clarification
* Validating the generated configuration, business config schema, and webhook details
