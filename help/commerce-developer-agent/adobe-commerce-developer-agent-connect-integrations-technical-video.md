# Adobe Commerce Developer Agent connect integrations

Generated code needs a place to run and a connection to your store. This stage integrates everything — hosting the code in App Builder, connecting it to your Adobe Commerce instance, and linking a GitHub repository — before the feature is enabled.

## Who is this video for?

* Commerce developers
* Solutions architects
* Backend engineers

## Video content

* Creating an App Builder project and workspace to host the code the developer agent created
* Watching the agent scaffold the project and surface outstanding setup items
* Adding the required Adobe Commerce as a Cloud Service API credential in the developer console
* Connecting the code to a specific Adobe Commerce Cloud Service instance
* To store and version the code, link a GitHub repository
