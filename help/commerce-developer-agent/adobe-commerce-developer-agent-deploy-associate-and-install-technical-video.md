# Adobe Commerce Developer Agent deploy, associate, install

With everything connected, the app is ready for production. This stage deploys the code, then associates and installs it in the Adobe Commerce admin so the new feature is enabled in the store.

## Who is this video for?

* Commerce developers
* Solutions architects
* Commerce administrators

## Video content

* Asking the developer agent to deploy from chat and confirming the exact organization, project, and workspace
* A pre-deploy validation pass, then streaming build and publish output as the code is deployed
* Associating the deployed app to a specific store from the Commerce admin's App Management screen
* Reviewing the app card — name, version, and the capabilities it adds (a webhook)
* Installing the app to activate the feature and confirming it is successfully installed
