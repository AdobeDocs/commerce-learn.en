# Adobe Commerce Developer Agent migrate existing code

Not every project starts from an empty configuration. This example migrates an existing extension to App Builder, moving from the PaaS Platform to Adobe Commerce as a Cloud Service, using the Migration Assessment Tool to feed the Developer Agent.

## Who is this video for?

* Commerce developers
* Solutions architects
* Backend engineers

## Video content

* Scanning an existing Commerce instance with the Migration Assessment Tool — complexity ratings, per-module impact, risk signals, and a rebuild, refactor, replace, or remove recommendation
* Reviewing a high-impact module's assessment, including its hooks, files, and a plain-language purpose summary that doubles as a ready-made prompt
* Sending the assessment straight into the Developer Agent with no manual copying
* To focus the first pass on specific capabilities, answer the agent's scoping questions
* Generating a blueprint of synchronous webhooks that replace the riskiest legacy logic, with an architecture diagram
* Building the implementation with a matching test file written alongside each handler
