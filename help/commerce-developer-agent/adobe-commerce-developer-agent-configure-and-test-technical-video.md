# Adobe Commerce Developer Agent configuration and testing

Once the app is installed, its limits and messages become business settings anyone can adjust — no code required. This stage configures the cart quantity limit and tests it live on the storefront to confirm the rule works.

## Who is this video for?

* Commerce developers
* Commerce administrators
* Merchandisers

## Video content

* Reviewing the business configuration the agent exposed — the maximum cart quantity and the shopper-facing message
* Lowering the maximum cart units per SKU from the default to a lower value and saving, with no code changes
* Adding products on the storefront and exceeding the configured limit
* Confirming the block and the exact error message, enforced live without a redeploy
