# Navigate store configuration and the System menu

Explore the Adobe Commerce Admin workspace, from filtering product attributes to customizing product grids and saving views. This video also introduces the [!UICONTROL Stores] menu and the configuration areas for general store information, catalog settings, security, customers, and sales.

## Who is this video for?

* Administrators and users managing an Adobe Commerce store
* Developers getting familiar with the Adobe Commerce Admin

## Video content

* Filter a fixed product attributes grid by attribute scope.
* Customize a product grid by showing or hiding columns and dragging columns into a different order.
* Filter products by color and save the filtered grid as a reusable view.
* Switch between the default view and saved views, and update an existing view.
* Navigate to store configuration and explore general, catalog, security, customer, and sales settings.

>[!VIDEO](https://video.tv.adobe.com/v/3473115?learn=on)

## Saved grid views

A saved view retains the grid setup for reuse. In the video's blue-products example, newly added products appear when they match the filter. Products stop appearing when their color no longer matches.

## Store configuration

The [!UICONTROL Stores] menu provides access to store settings. The configuration tour highlights store location and email addresses, currency, catalog display settings, security options, customer defaults, shipping methods, and payment methods.
